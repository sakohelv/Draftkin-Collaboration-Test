- [Download Lighting Test for Windows x64](https://github.com/sakohelv/Draftkin-Collaboration-Test/releases/download/paired-test-v1.1.1/Draftkin-Lighting-Studio-Test-Setup-1.1.1-x64.exe)

Open a shared project and choose **Document Exchange → Share files…**. Select files or an entire folder from your PC, tick the teams that should receive them and click **Send**. Folder paths travel with the files.

For CAD files already uploaded, open **Working files**. Choose **Share with…** beside a file, **Share folder…** beside a folder, or tick several items and choose **Share selected**. Each recipient must have an active appointment on the project.

If your role requires approval, click **Request approval**. The project manager opens the notification, reviews the files and recipients, and clicks **Approve & send** once for all selected teams.

Each receiving team gets one notification and one package in **Received**. Open the package in **Submitted** to see who has opened it. The sender can share up to 500 files per package, with a maximum of 512 MiB per file.
