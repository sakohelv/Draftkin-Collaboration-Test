# Draftkin Lighting Studio Test v1.0.1

[Download the Windows x64 installer](https://github.com/sakohelv/Draftkin-Collaboration-Test/releases/download/lighting-studio-test-v1.0.1/Draftkin-Lighting-Studio-Test-Setup-1.0.1-x64.exe)

Install **Draftkin Lighting Studio Test** on the Lighting tester’s PC. The reviewer opens **Draftkin Studio v1.1.23** on their PC. The installer uses its own Windows app identity and profile. You can keep Lighting v3.0.4, Studio and the earlier pilot installed alongside it.

## Try one presentation together

1. In Lighting Studio Test, sign in with your Draftkin Studio account. In **Projects**, select **+ New project**, give the job a name and create it. Project creation uses your company’s existing permissions. A company owner or administrator can create the project if you have a reviewer account.
2. In that project, open **Studio team → People & access**. Assign your colleague from the roster, or invite their Draftkin account to the test project. Give the colleague a role with presentation review and decision permissions. They can accept a pending invitation in their installed Studio app.
3. In Lighting, open **Presentations**, create a presentation and add a page using Studio’s editor. Use the Studio review action, choose the reviewer and decision owner, and send the version. For an internal check first, send a round to your Lighting reviewer and then share the checked version with the Studio reviewer.
4. In Studio, open the notification or the test project's **Studio presentation reviews**. Open the PDF, mark a specific page, save the feedback and request revisions. The reviewer must be the decision owner to return the round.
5. In Lighting, open the returned review from **Needs your attention** or **Presentation reviews**. Reopen the source on the author’s PC, revise and send the next version. The earlier PDF, markup and decision remain with the version reviewed.

The project appears in Studio with a **[Lighting Test]** prefix. If the reviewer creates the project in Studio first, start its name with **[Lighting Test]** and invite the Lighting author with presentation-editing access. Use Studio’s regular project workspace and its in-app presentation review.

## Lighting tools

The Projects sidebar opens the full Lighting technical workspace in a separate window. Its test project picker and sign-in manage technical files. Choose or create the matching technical project there. **Projects & presentations** brings you back to the project list. Editable presentation drafts live on the author’s PC. Shared review versions, annotations and decisions use the Studio project on the server.
