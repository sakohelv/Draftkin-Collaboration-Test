## View a discipline’s documents in Studio

Open your project, choose **Document Exchange**, and click a name under **Disciplines**. For example, **Lighting** opens **Sent to Lighting** and **Received from Lighting** together. Each direction shows its file count and lists the newest issues first. On smaller windows the two lists stack.

Click a filename to see its folder, package and exchange date. Choose **Open package** to view the issue and its files. If you sent a package to several disciplines, each discipline’s view shows its own delivery status. A drawing that came back from a discipline appears in the received list alongside the history of what Studio sent.

Use **All exchanges** to search across teams, stages and file types. Both Windows test installers carry version **1.1.3**.
