## Invite Lighting with a presentation

1. In Studio Test, open the project and choose **Project team → Invite discipline**.
2. Choose **Lighting** and enter the consultant’s account email. Review the checked stages and pick the PDF or saved presentation under **Attach a presentation**.
3. Select **Send invitation**. In Lighting Test, the recipient opens **Consultant invitations** and accepts. Lighting opens the received submission. Select **Preview** to read the PDF.
4. The recipient can return to **Document Exchange → Received** to find the same file. **Stages & programme** shows the stages assigned to Lighting.

A recipient who registers after the invitation may also need the existing account identity confirmation from the inviting Studio manager.

## Send a published presentation to an existing discipline

On the Studio computer that holds the original published PDF, open **Presentations → Published versions**. Choose the version, click **Share with disciplines**, tick the recipient, and click **Share presentation**. Lighting receives a notification. This workflow can happen before any client delivery or response.

For a presentation marked for Lighting in an earlier test build that never appeared in Received, use these steps once. The existing appointment still works. Repeating the same share for the same version and appointment keeps one receipt.

## Other disciplines and internal review

Other appointed disciplines open **Discipline invitations** in Studio Test with their own accounts. **Document Exchange → Send presentation** remains available for sending work through internal review. Editors request approval and a manager can review the PDF before issuing it. Use **New submission** for packages of several files.
