# Draftkin Studio Test and Lighting Test v1.1.0

- [Download Studio Test for Windows x64](https://github.com/sakohelv/Draftkin-Collaboration-Test/releases/download/lighting-test-v1.1.0/Draftkin-Studio-Test-Setup-1.1.0-x64.exe)
- [Download Lighting Test for Windows x64](https://github.com/sakohelv/Draftkin-Collaboration-Test/releases/download/lighting-test-v1.1.0/Draftkin-Lighting-Studio-Test-Setup-1.1.0-x64.exe)

Open an appointed project in Lighting and select **Project overview**. The project brief and scope appear beside a timeline of assigned stages. Each deliverable shows its own due date. On smaller screens the brief and scope sit above the timeline.

**Shared files** counts distinct attachments in packages received by the Lighting project. The same attachment in two packages counts once. **Open Received folder** opens that project's received packages in Document Exchange. This feature uses the signed-in member’s document permissions.

Studio Test v1.1.0 brings the Studio installer and in-app version up to the same release number as Lighting Test.
