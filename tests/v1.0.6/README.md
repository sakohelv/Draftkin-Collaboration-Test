## Which app does each person use?

| Team | App | Where to start |
| --- | --- | --- |
| Studio | Studio Test | Open the project or create a new test project. |
| Lighting | Lighting Test | Open **Consultant invitations** and accept the appointment. |
| Electrical, Mechanical, Plumbing, Structural or another discipline | Studio Test | Sign in with the invited account and open **Discipline invitations**. Accept to enter that discipline’s project workspace. |

Use separate accounts for the project teams. Other disciplines use the shared Documents and presentation tools in Studio Test. Lighting has its own technical tools.

## Appoint a discipline

In Studio, open **Project team → Invite discipline**. Choose a discipline or type its name, enter the consultant’s account email, and send the invitation. Repeat for each team. This screen lists the disciplines and shows when they have connected. **Invite Studio collaborator** is for colleagues on the Studio team.

Invitations arrive inside the recipient’s app. If the account is registered after the invitation, Studio receives a request to confirm the account.

## Send a saved presentation

1. Save the presentation in **Create & edit**.
2. Open **Document Exchange → Send presentation**. Pick the saved presentation and recipient. With one appointed recipient, the app fills it in. **Preview PDF** shows the file you will send.
3. A project manager can choose **Approve & send**. An editor chooses **Request approval**. The approving manager opens the notification, reviews the PDF and chooses **Approve & send** in the preview.
4. The recipient can open the notification or find the issue in **Received**. The sender can find it in **Submitted**. A later saved revision sent to the same discipline receives the next issue number.

Use **New submission** for multi-file packages and folder trees. A discipline can send a linked response to Studio. Studio selects the destination when it sends to an appointed discipline.
