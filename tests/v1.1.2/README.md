## Studio exchange register

Open a project and choose **Document Exchange → All exchanges**. Select a discipline to see the packages exchanged with that team. **Received** and **Submitted** describe the direction from Studio’s perspective. A submission to several disciplines appears once in All exchanges. Open it for the individual delivery receipts.

Switch from **Packages** to **Files** to search by filename or drawing number. You can narrow either view by stage or file type. Open a result to see its original issue. The register labels older packages without a recorded stage **Unassigned**. New file submissions can choose a stage.

## Organize project files in either app

Open **Received**, **Submitted**, **Drafts**, **Working files**, or a project folder. Select files, click **Move to…** or **Copy to…** and choose the destination. Choose **New folder** in the picker to create a nested folder and use it immediately. The change is shared with teammates in that project. **Undo** is available after filing.

The original issued package keeps its filenames, folder structure and delivery history. To send work back against a received issue, open the issue and choose **Respond to this package**.
