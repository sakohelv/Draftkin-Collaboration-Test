# Draftkin Studio Test and Lighting Test v1.0.2

Windows x64 installers for the consultant collaboration test. Each app has its own Windows shortcut and data folder. You can install these alongside production Studio and Lighting. The Lighting installer updates the earlier Lighting Studio Test if it is already installed.

- [Download Lighting Test v1.0.2](https://github.com/sakohelv/Draftkin-Collaboration-Test/releases/download/paired-test-v1.0.2/Draftkin-Lighting-Studio-Test-Setup-1.0.2-x64.exe)

## Test the workflow

Use separate registered cloud accounts for the Studio project lead, the Lighting lead and the Lighting reviewer. Three accounts represent three roles. The test can run on two PCs by signing into the reviewer account separately. Invitations and feedback arrive inside the apps.

1. In **Studio Test**, sign in and choose **New test project**. Give the project a name and create it.
2. Open the project and choose **Invite consultant / submissions**. Enter the Lighting lead’s registered email, describe the scope and list the deliverables. Choose **Send consultant invitation**.
3. In **Lighting Test**, the Lighting lead opens **Consultant invitations** and accepts. The project is available under **Consultant projects**. In the project, open **Lighting approvals & issue → Lighting team / assign reviewers** and invite the second Lighting account as a reviewer. The reviewer accepts in Lighting Test.
4. The Lighting author opens **Presentations**, creates the deck and selects **Send for Lighting review**. Choose the Lighting reviewer as the decision owner. The reviewer opens the shared PDF, adds any internal markup and approves the version when ready.
5. The Lighting lead opens **Lighting approvals & issue**, selects the deliverable and chooses **Send approved version to Studio**. An edit to the source draft requires a new internal review before the edited draft can be issued.
6. In **Studio Test**, open the review notification or **Invite consultant / submissions → Open review**. Mark up the PDF, then send the decision. Lighting receives the returned feedback in its project. For changes, edit the source presentation and repeat the internal review and issue steps.

Internal Lighting review notes stay with the Lighting team. Studio receives the issued PDF. Each submitted revision has its own review history.

These are unsigned Windows test installers. The SHA256SUMS.txt release asset lists the checksums for both downloads.
