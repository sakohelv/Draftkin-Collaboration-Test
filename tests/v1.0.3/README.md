# Draftkin Studio Test and Lighting Test v1.0.3

- [Download Draftkin Lighting Test for Windows x64](https://github.com/sakohelv/Draftkin-Collaboration-Test/releases/download/paired-test-v1.0.3/Draftkin-Lighting-Studio-Test-Setup-1.0.3-x64.exe)
- [Download Draftkin Studio Test for Windows x64](https://github.com/sakohelv/Draftkin-Collaboration-Test/releases/download/paired-test-v1.0.3/Draftkin-Studio-Test-Setup-1.0.3-x64.exe)

Install v1.0.3 on both sides. Each installer updates the corresponding test app and can run alongside the production app. These are unsigned Windows test installers.

## Share with two people

1. **Studio** opens the project, chooses **Invite consultant / submissions**, and invites the Lighting user's registered email. If the Lighting user has already accepted a consultant invitation for this project, skip this step.
2. **Lighting** accepts the invitation in Notifications. Open a presentation and click **Share with Studio** in the editor. Check the PDF preview, the Studio project and the deliverable. Leave the review method on **Lighting lead checks and sends**, then click **Send to Studio**. For a presentation created in a separate Lighting test project, choose the invited Studio project in the same dialog.
3. **Studio** opens the notification to see the issued PDF. Use **Review decision** to approve or request changes with markup or a note. **Lighting** receives a notification that opens the reviewed version.

## Optional colleague approval

In **Share with Studio**, the appointed Lighting lead can choose **A colleague approves and sends** as the project's review method. Select a Lighting teammate who has decision access, then click **Request approval**. The reviewer opens the alert and chooses **Approve & send to Studio**. Studio receives the approved version automatically.

## Notifications

The notification inbox covers your consultant test projects across workspaces. Open an alert to go to the invitation, appointment or PDF. The unread badge stays available after the brief alert disappears. While the app is closed, incoming events remain in your inbox for your next sign-in.

The SHA256SUMS.txt release asset lists the checksums of both installers.
