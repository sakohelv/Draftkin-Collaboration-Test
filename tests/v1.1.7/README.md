## Link a presentation to the project programme

In Lighting, open **Document Exchange → Send presentation**, choose the presentation and select its **Assigned deliverable**. Choose **Separate submission (unplanned)** for additional work outside the programme. Revisions of a linked presentation keep their deliverable, including revisions sent from **Presentations → Reviews**. Studio’s **Stages & programme** uses the latest issued review decision when reporting completion.

## Include source files in a discipline invitation

In Studio, open the project and select **Invite discipline**. Under **Share source files with this discipline**, check each source file you want the consultant to receive. The files come from the project’s **Source material**. The consultant can open them in **Document Exchange → Received** after accepting.

## Read a review at a larger size

Returned markups open in an expanded comparison view. Choose **Markup only**, **Slides only**, or **Side by side**. Use the zoom control to read small notes at up to 300% of the fitted width. PDF previews and the markup drawing window also have zoom controls.

Click anywhere in the project start date field to open its calendar.
