# Draftkin Studio Test and Lighting Test v1.0.4

Download the Windows x64 installer for your role. Both apps can run on the same PC with different accounts, or on separate PCs.

- [Draftkin Studio Test installer](https://github.com/sakohelv/Draftkin-Collaboration-Test/releases/download/paired-test-v1.0.4/Draftkin-Studio-Test-Setup-1.0.4-x64.exe)
- [Draftkin Lighting Test installer](https://github.com/sakohelv/Draftkin-Collaboration-Test/releases/download/paired-test-v1.0.4/Draftkin-Lighting-Studio-Test-Setup-1.0.4-x64.exe)

## Create the project and invite people

1. Open **Studio Test**, create an account, choose **New test project**, and enter a project name.
2. To add someone on your Studio team, open the project and choose **Invite Studio collaborator**. Enter their email, select a project role, and send. They open **Studio Test → Notifications** or **Invitations** and accept.
3. To appoint the lighting designer, choose **Invite Lighting consultant**. Enter their Lighting account email, the scope, and the deliverables. They open **Lighting Test → Notifications** or **Consultant invitations** and accept. Both kinds of invitation are delivered inside the recipient’s app.
4. If the Lighting designer registers after the invitation was sent, their first acceptance asks you to confirm the new account. Open the Studio notification, check the identity, and click **Confirm Lighting account**. The designer can then open Invitations and accept to enter the project.

## Review a presentation

In Lighting Test, open a presentation and choose **Share with Studio**. Preview the PDF, confirm the project and deliverable, then send. Studio’s notification opens that PDF for review. The Lighting designer receives the decision in their own notification inbox.

Use separate accounts for the Studio project owner, the Studio collaborator, and the external Lighting consultant. These installers use the paired test workflow and install alongside the production apps.
